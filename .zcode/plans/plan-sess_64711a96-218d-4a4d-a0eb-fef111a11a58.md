# Frontend code-quality deep dive — findings & fix plan

## Verdict

The frontend (~68k source lines, 445 source + 233 test files) is **unusually disciplined** — better than most production codebases on every axis I measured. The issues found are specific and few; none are architectural.

**Verified strengths:** `strict: true` with **zero** `any`/`as any`/`@ts-ignore` and no non-null assertions in source (398 `unknown` uses instead); 0 console.logs, 0 TODOs, 0 commented-out code; lint enforced at `--max-warnings 0`; a heavily engineered API client (deduped token refresh with epoch guard, idempotent-method retries, 5s GET micro-cache, SSE watchdogs, abort-on-logout); layered error boundaries; 516 aria attributes with focus-trapped modals; 233 test files. Security: **no XSS surface** (no dangerouslySetInnerHTML/eval anywhere; react-markdown without rehype-raw; URL scheme allowlist), access token in memory only, logout purges stores + caches + service worker, Tauri capabilities minimized, no secrets in the bundle.

## Issues found (ranked)

1. **Partial runtime validation** — only ~9 of ~165 API endpoints are zod-validated; the rest cast parsed JSON blindly (`api/client.ts:471,513`). Shape drift fails deep in the UI instead of at the boundary.
2. **Error-message idiom duplicated 72×** — `err instanceof Error ? err.message : String(err)` with no shared helper; plus 25 hand-rolled `ApiError.code` branches. Inconsistent handling, easy to bypass toast/i18n conventions.
3. **i18n rollout incomplete** — `inspector` 0/19 files converted, `library` 0/9, `flow` 2/17, `search`/`analyzer`/`collaboration` 0/N ship hardcoded English; the enforcement test only guards converted dirs.
4. **tsconfig gaps** — missing `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `noFallthroughCasesInSwitch` (the remaining unsound spots).
5. **Cytoscape mount effects fully disable `exhaustive-deps`** (`useCytoscapeGraph.ts:206,248`, `GraphView.tsx:89,119`) — stale props have no reload path.
6. **`DataTable` falls back to index keys** (`charts/DataTable.tsx:62`) — row-state bleed risk in sorted/filtered tables; 40 `key={index}` sites overall.
7. **Coverage floor ~50% lines** — `azureFoundryStore.ts` (758 lines), `OrganizationsPanel.tsx` (804) have no erosion protection.
8. **God files** — `useChatStreamEngine.ts` (1,198), `chatStore.ts` (1,078), `OrganizationsPanel.tsx` (804), `AITab.tsx` (796).
9. **Silent unlogged catches** in `authNotice.ts`/`ProfileSection.tsx` (deliberate, but invisible when debugging).
10. **Security MEDIUM:** refresh token persisted in localStorage on "remember me"/SSO (`authStore.ts:71,170`) — XSS-exfiltratable; the durable fix is an HttpOnly-cookie refresh flow (backend work).
11. **Toolchain majors behind:** React 18, Vite 5, Tailwind 3 (current: 19/7/4) — staged upgrades, not urgent.
12. **Trivial:** `frontend/test-results/.last-run.json` is git-tracked (needs `git rm --cached`, which is yours to run).

## Proposed fixes (phased, all test-protected)

**Phase 1 — mechanical, zero-behavior-change (~half a day):**
- Add `lib/getErrorMessage.ts` (handles `ApiError` codes, Error, strings, unknown) and migrate all 72 idiom sites + fold in the 25 ApiError-code branches where a shared mapping fits
- Add `logger.warn` to the silent catches in `authNotice.ts` / `ProfileSection.tsx`
- `DataTable`: require `rowKey` (compile-error-driven migration of the few callers)
- tsconfig: add `noFallthroughCasesInSwitch` (cheap), then `noUncheckedIndexedAccess` and fix fallout (bounded; if it exceeds ~50 error sites, report back instead of forcing)

**Phase 2 — staged hardening:**
- Extend zod `requestValidated` to the remaining domain modules' core GET/POST reads (flow list, library, governance, providers, chat history), prioritizing endpoints whose shapes already have Go-side mirrors documented
- Cytoscape effects: replace whole-effect disables with explicit init-once + tracked-input reload
- i18n: convert `inspector` → `library` → `flow`/`search`/`analyzer`/`collaboration` directory-by-directory, extending the coverage test's locked set as each lands

**Phase 3 — larger, separate efforts (only on request):**
- God-file decomposition (chatStore / useChatStreamEngine / OrganizationsPanel / AITab) — real refactor work, needs its own careful pass
- HttpOnly-cookie refresh flow (backend + frontend contract change)
- React 19 / Vite 7 / Tailwind 4 upgrades

**Explicitly out of scope:** Playwright runs, `%APPDATA%` settings, git operations.

## Verification

After each phase: `npm run lint` (must stay at 0 warnings), `npm run typecheck`, `npm test` (vitest), plus build. No Playwright runs. Everything stays uncommitted for your review.
